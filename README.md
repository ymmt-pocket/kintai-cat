# KINTAI-CAT 2.0

Google Driveで自分の勤怠をスマホ・PC間で共有する、HTML/CSS/JavaScriptだけのアプリです。

## 今回の更新

- Google接続画面を追加。起動時には端末の保存データを表示せず、Drive APIで接続したアカウントを確認してから読み込みます。
- 「このブラウザーに記録を残す」をアカウント・ブラウザーごとに選択できます。この設定はDriveへ同期しません。
- 自社・Lycheeのどちらかが○なら実績確定。両方が未チェックなら予定・未確定です。報告済みの時間を変更すると、確認後に両方のチェックを外します。
- 集計画面に月の確定実働、所定超過、月の見込み、未確定日数、週別一覧を追加。
- HTML/CSS/JavaScriptをファイル分割しました。ビルドやパッケージのインストールは不要です。

## 更新手順（PC推奨）

1. 今のアプリで「出力 → バックアップ保存」を実行してください。スマホ・PCに未同期の入力がある場合、それぞれ同じGoogleアカウントで同期を完了します。
2. ダウンロードしたZIPを展開します。
3. https://github.com/ymmt-pocket/kintai-cat を開き、Add file → Upload files を選びます。
4. 展開した中の `index.html`、`css` フォルダー、`js` フォルダーを同時にドラッグします。README.md・testsも一緒に追加できます。ZIPそのものや外側のkintai-cat-v2フォルダーはアップロードしません。
5. `index.html` がリポジトリ直下、`css/style.css`、`js/app.js` などが各フォルダー内にあることを確認し、Commit changesを押します。一度のコミットでまとめて更新してください。
6. GitHub Pagesの反映後、https://ymmt-pocket.github.io/kintai-cat/ を開き直します。スマホ・PC両方の古いタブも閉じて更新してください。
7. 同じGoogleアカウントで接続し、過去の時間・チェックが表示されることを確認します。「設定」で端末保存の選択を確認してください。

URLとGoogle OAuthクライアントIDは既存のままです。配信URLを変えなければ、今回の更新に伴うJavaScript生成元の変更は不要です。

## 保存・ログアウト

- 新規利用するブラウザーでは端末保存はOFFです。ONにすると、変更をブラウザー内に保存し、Driveへ自動同期します。
- 旧版にアカウント別の端末記録がある場合、未同期分を守るため、その端末では保持を継続し「旧版の端末記録を引き継いだ」という案内を表示します。設定で継続または削除を選べます。
- 端末保存OFFの場合、変更は画面のメモリーに保持してDriveへ同期します。同期前に画面を閉じたり再読み込みすると、未同期分を失う可能性があります。終了時のブラウザー警告は補助であり、特にスマホでは必ず表示されるとは限りません。
- 端末保存ONでも、Googleのアクセストークンは永続保存しません。
- ログアウト時は画面内の記録とトークンを消します。端末保存ONなら端末の記録は残し、次回のGoogle接続確認後に読み込みます。
- 未同期で、端末にも安全に保存できていない記録がある間は、ログアウトや別アカウントへの切替を止めます。同じアカウントで再接続して同期してください。
- 「このアカウントの端末記録を削除」は端末保存をOFFにし、そのアカウントの端末記録を削除します。Drive上の記録は削除しません。未同期がある間は操作を止めます。
- 旧版の未接続（guest）記録は勝手にアカウントへ混ぜません。必要な場合だけ、設定から明示的にコピーできます。この操作は元のguest記録を削除しません。
- トークン期限切れ後は同じ画面内の記録を保持し、Googleへの再接続を求めます。画面を開き直すと接続確認から始まります。完全オフラインでの初回起動には対応していません。
- 端末保存は暗号化保管庫ではありません。同じブラウザー・同じサイト生成元のスクリプトから読み取り可能です。自分専用の端末で利用してください。
- HTML・JS・CSSは公開ファイルです。画面遷移のガードはUXのためであり、データの権限はGoogle側のアクセストークン／Drive APIで管理します。URLから所有者ID・権限を採用しません。

## 集計ルール

- 自社またはLycheeが○で、勤務時間がある日を確定実績として集計します。チェックが未入力の過去日は、未確定として扱います。
- 月の見込みには、未来の日の標準時間・未確定分を含みます。
- 週は初期設定で月曜〜日曜。設定で日曜始まりも選べます。月をまたぐ週は7日間をまとめるため、週別合計を足しても月合計と一致しない場合があります。
- 日またぎ勤務は開始日へ集計します。
- 所定超過は各確定日の `max(実働分 − 所定分, 0)` の合計。初期の所定時間は1日08:00です。短い日と相殺しません。給与・法定時間外・深夜割増の計算機能ではありません。
- 所定時間は適用開始日付きで設定でき、過去の適用期間を保持します。同じ開始日で保存すると、その期間の設定を変更します。開始日以前にルールがない場合は08:00を使用します。
- 同期で変更が競合した場合、該当する集計を一時的に非表示にし、解決後に表示します。
- 祝日自動入力は既存と同じ2026・2027年分です。他の年は日別入力します。

## CSV・バックアップ互換性

CSVは従来どおり `月,日付,勤務開始,勤務終了,実働時間,総実働` の6列。総実働は最終行だけです。CSVは予定・未確定・未来の初期値も含む月全体を出力します。集計画面の「確定実働」と対象が異なります。

既存のDrive専用領域・`kintai-cat-v1-*.json` 変更履歴を継続使用し、既存ファイルの削除・一括上書きは行いません。v1のJSONバックアップも読めます。追加した集計設定はsettingsの追加フィールドです。アップデート後は両端末を新しい版へ切り替えてください。

## ファイル

- index.html: 画面構造
- css/style.css: デザイン・スマホ対応
- js/app.js: 起動・遷移・編集画面・設定
- js/auth.js: Google接続・ログアウト
- js/storage.js: 端末保存・Google Drive同期
- js/attendance.js: 勤務時間・入力検証・変更履歴・CSVの純粋計算
- js/summary.js: 実績・週別・所定超過の集計
- js/export.js: CSV・バックアップの入出力
- tests/attendance.cjs: Node.jsで実行する計算・同期・移行テスト

他の利用者も各自のGoogleアカウントのDriveへ保存します。Google OAuth同意画面がテスト公開の場合、利用者をテストユーザーに追加するなど、Google側の利用対象の設定も必要です。

## 検証

`node tests/attendance.cjs`

- 時刻・休憩・日またぎ・閏年・祝日・CSV6列と最終行のみ合計
- OR条件で実績確定、相殺しない所定超過、適用日付き所定時間、月をまたぐ週集計
- 起動時・URL直打ちでの表示制限、Googleアカウント別の分離
- テスト用Drive応答で、2端末間の同期・競合解決・通信失敗後の再試行
- 端末保存OFF、端末ごとのON/OFF、ログアウト時の未同期保護、旧版記録の移行、保存容量不足
- ブラウザーでスマホ幅・PC表示、4桁時刻入力、報告チェックから集計への反映、ログアウト表示を確認

実Googleアカウントでの認可・Driveへの接続は公開URLへの更新後に確認が必要です。テスト用画面・架空の勤怠データ・モック認証コードはこの配布ZIPに含めていません。
